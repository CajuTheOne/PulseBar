# PulseBar — настройки, файлы, команды

## Где что лежит

| Что | Где |
|---|---|
| Программа | `C:\Program Files\PulseBar\` (`PulseBar.exe` — строка, `PulseBar.Sensor.exe` — служба) |
| Исходники | https://github.com/CajuTheOne/PulseBar, рабочая копия `N:\AI\Tools\PulseBar` |
| Настройки | `%APPDATA%\PulseBar\settings.json` (с 2.1) |
| Журналы | строка — `%LOCALAPPDATA%\PulseBar\pulsebar.log` (при 512 КБ уходит в `pulsebar.old.log`), служба — `%ProgramData%\PulseBar\sensor.log` (очищается при 64 КБ) |
| Отчёты для отладки | при галочке «Собирать данные для отладки»: очередь `%LOCALAPPDATA%\PulseBar\reports\` (последние 20, `index.json`), на NAS — `\\192.168.1.61\Leo\AI\Tools\PulseBar\reports\<ID ПК>\`; чек-лист тестировщика — [TESTING.md](TESTING.md) |
| Клавиатура и мышь | `%APPDATA%\PulseBar\logitech.json` (профили, переключатели `keyboardOn` / `mouseOn` / `headsetOn`, выбор `keyboardDevice` / `mouseDevice` / `headsetDevice`), `%APPDATA%\PulseBar\devices.json` (устройства Logitech, бывшие на связи: имя, вид, функции), отчёты «Сохранить отчёт об устройствах» — `%LOCALAPPDATA%\PulseBar\devices-report-*.txt` |
| Автозапуск | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `PulseBar` |
| Служба | `PulseBarSensor` (LocalSystem, автоматически), канал `\\.\pipe\PulseBar.Sensor` |

## Меню (правый клик по строке)

| Пункт | Что делает |
|---|---|
| Update to x.y | появляется, когда на GitHub есть новая версия: скачать и установить (UAC) |
| Settings… | окно настроек |
| Edit mode | режим правки расположения (см. ниже); в нём же — «Добавить разделитель», «Удалить разделитель» (если щёлкнули по нему), «Сбросить расположение» |
| Profile | профиль Logitech (если включено управление Logitech и профилей больше одного) |
| Task Manager | Диспетчер задач (то же — двойной клик по строке) |
| Exit | выход |

## Окно настроек

Отдельный процесс `PulseBar.exe --settings <вкладка> <окно строки>` (WPF, тема Fluent). Изменения применяются сразу:
окно сохраняет `settings.json` и сообщает строке, строка перечитывает файл. Пока окно открыто, строка раз в секунду
пишет `%LOCALAPPDATA%\PulseBar\status.json` (показания для превью, данные Claude, список видеокарт).

| Вкладка | Что там |
|---|---|
| Вид | превью; «Одна строка» / «Две строки» (с раскладкой заново); «Свой вид» — список сохранённых видов, «Загрузить», «Сохранить текущий…» (то же имя заменяет вид), «Удалить»: вид — раскладка, элементы, стили и полосы, цвета; язык, пороги и ключи не входят; «Элементы» — плитки CPU, GPU, VRAM, RAM, заряд (нажата — на строке); «ИИ» — плитки Claude, ChatGPT, Grok, DeepSeek, «…» — какие плитки в строке (и Gemini — пока без данных) и ключ API DeepSeek; «Расположение на панели задач» (свёрнуто): режим правки, привязка к соседям, расстояния, «Добавить разделитель», «Сбросить расположение»; «Дополнительно»: вид, размер текста, частота, видеокарта, подсказка и график, ГБ, встраивание, полноэкранные, значок в трее, автозапуск, язык |
| Пороги и цвета | палитра показателей — норма, предупреждение, перегрузка (клик по образцу — выбрать цвет); жёлтый/красный для CPU, GPU, VRAM, RAM, Claude, ChatGPT, Grok; для заряда клавиатуры и мыши и баланса DeepSeek — «при ≤»; «По умолчанию» сбрасывает и цвета |
| Клавиатура (название — марка и модель найденной клавиатуры, с 2.4.0-beta.8) | вверху — «Клавиатуры в PulseBar» (выключено — вкладка пустая, клавиатура в своей памяти, заряда на панели нет), заряд и умения клавиатуры, «Определить» (список найденных клавиатур с тем, что PulseBar с ними умеет, выбор, какой управлять, отчёт об устройствах). Разделы — по функциям, которые клавиатура заявила; клавиатура другой фирмы или без профилей в памяти — только настройки Windows. Ниже — профиль и «…» (создать, копировать, переименовать, удалить, поставить на M1/M2/M3, программы для автопереключения, скопировать цвета из другого профиля) и состояние клавиатуры. «Общие»: задержка и скорость автоповтора, мигание курсора (настройки Windows), «Управлять устройствами Logitech», приглушение при простое, предупреждение о «Динамическом освещении», «Вернуть заводские профили», «Резервная копия памяти». «Подсветка»: клавиши и логотип (выкл., цвет, дыхание, цикл, волна; период), яркость; в статичном режиме — редактор цветов: кисть с протяжкой (правая кнопка — базовый цвет), пипетка, «Все клавиши», сброс, отменить/повторить (Ctrl+Z / Ctrl+Y), последние цвета, логотип — квадратик над G1. «Клавиши G»: G1–G5 и MR (сочетание, медиа, текст, запуск, макрос; пометка «с PulseBar» / «и без PulseBar»). Всё без прокрутки |
| Наушники (название — марка и модель, с 2.4.0-beta.10) | «Наушники в PulseBar» (выключено — вкладка пустая, наушники не ищутся), заряд и связь, «Определить» — список наушников Bluetooth (заряд — тот, что Windows показывает в «Bluetooth и устройства», последний известный — у отключённых) и выбор, чей заряд показывать; «Сохранить отчёт об устройствах» |
| Мышь (название — марка и модель найденной мыши) | «Мыши в PulseBar» (выключено — вкладка пустая, мыши не ищутся, заряда на панели нет); заряд и что PulseBar умеет, «Определить» — список найденных мышей и выбор, чей заряд показывать, «Сохранить отчёт об устройствах»; скорость указателя, повышенная точность, двойной щелчок, колесо, смена кнопок (настройки Windows) |
| ИИ | вкладки Claude, ChatGPT, Grok, DeepSeek. Claude: стиль блока (выкл., компактный, большой), полосы большого стиля, аккаунт (открытый в приложении Claude или вход Claude Code), состояние данных, частота запросов к claude.ai. ChatGPT: стиль и свои полосы, состояние (5 ч, 7 дней со сбросом, когда обновлено, откуда). Grok: показывать на строке, состояние. DeepSeek: показывать на строке, ключ API (задать, удалить), баланс и состояние |
| О программе | версия, проверка и установка обновлений, бета-версии, ссылки |

## Режим правки и расположение

Элементы — `cpu`, `gpu`, `vram`, `ram`, `claude`, `battery` и разделители `sep1`, `sep2`, … — лежат группами. Группа —
элементы, прижатые друг к другу (между блоками `snapGap`, рядом с разделителем `sepGap`), и её правый край на
расстоянии `x` от трея. В режиме правки (меню или «Вид»; рамки вокруг элементов):

- тянуть элемент — он выходит из своей группы (остальные смыкаются); отпущенный над группой встаёт в ближайший
  промежуток, рядом с краем другой группы (ближе 24 px) — прилипает к ней, иначе становится отдельной группой;
  с выключенной привязкой — всегда отдельно, где отпустили;
- с Shift — двигаются все группы вместе;
- правый клик — добавить / удалить разделитель, сбросить расположение;
- Esc или тот же пункт — выход, расположение сохраняется (и после каждого перетаскивания тоже).

Промежутки между группами прозрачны для мыши. Расположение меняет только строка: окно настроек присылает ей
команды (`PulseBar.EditMode`, `PulseBar.ResetLayout`, `PulseBar.AddSeparator`) и не перезаписывает `groups`.

## settings.json

С 2.1 настройки — `%APPDATA%\PulseBar\settings.json`. `settings.ini` от 1.x/2.0 переносится при первом запуске и
остаётся как `settings.ini.bak`. Неизвестные ключи игнорируются; некорректные значения заменяются значениями по
умолчанию или ограничиваются диапазоном. Пороги — массивы `[жёлтый от, красный от]`.

| Ключ | По умолчанию | Значения |
|---|---|---|
| `layout` | `0` | `0` — одна строка, `1` — две строки |
| `language` | `en` | `en`, `ru`, `uk`, `de`, `fr`, `es`, `pt`, `it`, `pl`, `zh`, `ja` |
| `blueNormal` | `false` | синий цвет нормы |
| `textSize` | `1` | `0` мелкий, `1` обычный, `2` крупный |
| `intervalMs` | `1000` | 250…10000 |
| `hideFullscreen` | `true` | прятать в полноэкранных приложениях |
| `showRamGb` | `true` | объём в ГБ у RAM и VRAM |
| `groups` | нет | расположение: `[{"x": 102, "items": ["cpu", "sep1", "gpu", …]}, …]`; нет — всё в ряд у трея |
| `snap` | `true` | привязка к соседям при перетаскивании |
| `snapGap` / `sepGap` | `20` / `10` | расстояние между прилипшими блоками / рядом с разделителем, px при 100 % |
| `claudeStyle` | `1` | лимиты Claude: `0` выкл, `1` компактный, `2` большой |
| `batteryOrder` | `keyboard,mouse,headset` | порядок значков в блоке заряда (с 2.4.0-beta.11, часть вида): в двух строках 1-й над 2-м, 3-й рядом; выключенные и отключённые пропускаются |
| `headsetBattery` | `20,10` | порог заряда наушников: жёлтый / красный при этом и ниже |
| `claudeOnStyle` / `gptOnStyle` | `1` | вид выключенного блока Claude / ChatGPT: плитка в «Виде» включает его таким же (с 2.4.0-beta.8) |
| `claudeBarLength` / `claudeBarHeight` / `claudeSegments` | `78` / `8` / `10` | большой стиль Claude: длина 40…240 и высота 4…16 полос, px при 100 %; сегментов 5…20, `0` — сплошная |
| `gpu` | `""` | `VEN_xxxx&DEV_xxxx` выбранной видеокарты; пусто — автоматически дискретная |
| `trayIcon` | `true` | значок в трее |
| `embed` | `true` | внутри панели задач / поверх панели |
| `beta` | `false` | получать бета-версии |
| `debugReports` | `false` | собирать и отправлять отчёты для отладки (с 2.4.0-beta.12) |
| `showCpu`, `showGpu`, `showVram`, `showRam`, `showBattery` | `true` | показ блоков |
| `trayGap`, `groupGap`, `blocks`, `showClaude` | — | из 2.0–2.1 beta.2: используются только для расположения по умолчанию (`x`, `snapGap`, порядок) и переносятся сами |
| `hoverTip` / `hoverChart` | `true` / `false` | подсказка при наведении / график за 60 с в ней |
| `claudeFollowApp` | `true` | чьи лимиты Claude: `true` — аккаунта, открытого в приложении Claude; `false` — аккаунта Claude Code |
| `claudeInterval` | `5` | минут между запросами к claude.ai, 1…15 |
| `cpuLoad` / `cpuTemp` / `gpuLoad` / `gpuTemp` / `vram` / `ram` / `claude` | `[60,85]` / `[75,90]` / `[60,85]` / `[70,83]` / `[70,85]` / `[70,85]` / `[70,90]` | пороги |
| `kbBattery` / `mouseBattery` | `[20,10]` | заряд: жёлтый при ≤, красный при ≤ |

Ручные правки файла применяются после перезапуска PulseBar.

## Командная строка

| Команда | Что делает |
|---|---|
| `PulseBar.exe` | обычный запуск (второй экземпляр ждёт до 3 с и выходит, если первый не закрылся) |
| `PulseBar.exe --dump` | одно измерение всех датчиков в `%TEMP%\PulseBar-dump.txt` (диагностика) |
| `PulseBar.exe --autostart on` / `off` | включить/выключить автозапуск текущего пользователя |
| `PulseBar.exe --debug-send ["описание"]` | отчёт для отладки от запущенной строки, как кнопка «Отправить» (нужна галочка «Собирать данные для отладки» или переменная `PULSEBAR_DEBUG_REPORTS=1` у строки) |
| `PulseBar.exe --logi-diag [txt]` | диагностика клавиатуры Logitech: окно просит нажать M1–M3, MR, G1–G5, журнал пакетов в `%LOCALAPPDATA%\PulseBar\logi-diag-*.txt` (G HUB закрыт; строка на это время отпускает клавиатуру) |
| `PulseBar.exe --logi-backup <json>` | копия встроенной памяти клавиатуры (только чтение) |
| `PulseBar.exe --logi-call <функция hex> <fn> [аргументы hex]` | один запрос HID++ к клавиатуре (для разбора ошибок; можно при работающей строке), ответ — в `%LOCALAPPDATA%\PulseBar\logi-call.txt` |
| `PULSEBAR_LOGI_TRACE=1` (переменная окружения) | строка пишет все пакеты HID++ в `%LOCALAPPDATA%\PulseBar\logi-trace-*.txt` |
| `PulseBar.exe --settings [вкладка]` | окно настроек (вкладки 0–5: вид, пороги и цвета, клавиатура, мышь, ИИ, о программе); без окна строки изменения применятся при её следующем запуске |
| `PulseBar.exe --shot-settings <png> <вкладка>[:<внутренняя>] [expand\|-] [язык]` | нарисовать вкладку настроек в PNG без показа окна (диагностика; `2:0` — «Клавиатура» → «Общие»); профили Logitech берутся из временной копии |
| `PulseBar.Sensor.exe --dump` | температура CPU напрямую через PawnIO (от администратора) |
| `PulseBar.Sensor.exe --console` | служба в окне консоли (отладка, от администратора; саму службу перед этим остановить) |

## Сборка, установка, удаление

См. [README](../README.md#сборка): `build.ps1` собирает программу и установщик Inno Setup
(`installer\PulseBar.iss`), GitHub Actions публикует его по тегу `v*`.

Установщик (`PulseBar-Setup-<версия>.exe`, права администратора): закрывает PulseBar и службу, удаляет PulseBar 1.x
(задачу `\AI Tools\PulseBar` и папку `C:\Program Files\AI Tools\PulseBar`), при необходимости ставит .NET 9 Desktop
Runtime и PawnIO, копирует файлы в `C:\Program Files\PulseBar`, создаёт/обновляет службу `PulseBarSensor`,
включает автозапуск и запускает строку. Ключи для тихой установки: `/SILENT` или `/VERYSILENT`, `/SUPPRESSMSGBOXES`,
`/NORESTART`; так же его запускает обновление из программы. Удаление — «Параметры → Приложения» (настройки в
`%APPDATA%\PulseBar` остаются).

Требования: Windows 10/11 x64, .NET 9 Desktop Runtime; для температуры CPU — AMD Ryzen (Zen) или Intel Core
и драйвер PawnIO. Для сборки — .NET SDK 9 и Inno Setup 6.
