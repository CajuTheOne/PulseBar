## 2.0 — основа (бета 2.0.0-beta.2 — 30.10.2026)

- Публичный репозиторий `CajuTheOne/PulseBar` (MIT). Рабочая копия — `N:\AI\Tools\PulseBar` (NAS); `publish\`,
  `releases\`, `config\` в git не входят.
- Сборка релизов — GitHub Actions по тегу `v*`: публикация, упаковка Inno Setup, `PulseBar-Setup-<версия>.exe` в Releases.
  Тег с `-` (например `v2.0.0-beta.1`) — пре-релиз. Без цифровой подписи.
- Установщик Inno Setup: `C:\Program Files\PulseBar`, проверка и установка .NET 9 Desktop Runtime и PawnIO,
  удаление старой версии (задача `\AI Tools\PulseBar`, папка `C:\Program Files\AI Tools\PulseBar`),
  удаление через «Приложения».
- Служба `PulseBarSensor` (LocalSystem): температура CPU через PawnIO — AMD Ryzen (`AMDFamily17`) и Intel (`IntelMSR`).
  Основная программа работает без прав администратора и получает температуру по именованному каналу.
- Строка — дочернее окно панели задач (`Shell_TrayWnd`), как у Claude Code Usage Monitor; пересоздаётся после
  перезапуска Проводника. Если встроиться не удалось — прежний способ (окно поверх панели).
- Автозапуск — `HKCU\...\Run` (без прав), а не задача Планировщика.
- Обновления: проверка GitHub Releases при запуске и раз в сутки; точка на строке и пункт меню
  «Обновить до x.y»; установка по клику (один запрос UAC). Настройка «Получать бета-версии».
- Датчики CPU/GPU/RAM — без изменений; отсутствие железа не приводит к ошибкам.

## 2.1 — окно настроек и Claude (бета 2.1.0-beta.1 — 31.10.2026)

- Окно настроек на WPF (.NET 9, тема Fluent), отдельным процессом (WPF в строке занимал +105 МБ навсегда): Вид (пресеты + «Дополнительно»), Блоки (порядок перетаскиванием,
  вкл/выкл), Пороги, Клавиатура, Мышь, Claude, О программе / обновления. Живое превью строки.
- Короткое меню правого клика: Настройки…, Диспетчер задач, Обновить до x.y, Выход.
- Настройки в `settings.json`; `settings.ini` и `logitech.json` переносятся автоматически (старые — `.bak`).
- Подсказка при наведении на блок: график за 60 с и подробности.
- Клавиатура Windows (задержка и скорость автоповтора, мигание курсора), мышь Windows.
- 11 языков: RU и EN — вручную, остальные — перевод локальной моделью на ELLE с проверкой.
- Блок «CLAUDE»: `5h %` и `7d %`, пороги 70/90 %, время до сброса — в подсказке.
  - `GET https://api.anthropic.com/api/oauth/usage`, заголовок `anthropic-beta: oauth-2025-04-20`,
    токен из `~\.claude\.credentials.json` (читать при каждом опросе; токен продлевает сам Claude Code).
  - Опрос раз в 5 мин (настройка 1–15 мин), при 429 — ждать `Retry-After`. Было «раз в 2 мин»: эндпоинт режет
    частые запросы (429 с ожиданием до часа), основной источник — история приложения Claude (согласовано 31.10.2026).
  - Токен истёк — последние значения из `%APPDATA%\Claude\plan-usage-history.json`, блок бледный, «устарело».
  - Не вошёл — блок скрыт. Квоту не тратить (никаких `claude -p`, пробных сообщений).
  - Эндпоинт недокументирован; формат меняется (`five_hour`/`seven_day` → массив `limits`) — поддержать оба.

## 2.2 — новый модуль Logitech (бета 2.2.0-beta.1 — 31.10.2026, заменяется 2.3)

Гибрид «память клавиатуры / режим PulseBar» оказался нестабильным: одно нажатие M1 в журнале давало «M1» и сразу
«M2», клавиатура прыгала между режимами, а в памяти оставались старые профили G HUB (профиль 2 — «дыхание»
#00DCFF, отсюда «просто синяя»). Решено переписать модуль заново (2.3). Диагностика 2.3 нашла ещё две причины:
соседние M1 и M2 нажимаются вместе (маска 03), а «Динамическое освещение» Windows через службу Logitech LampArray
красит клавиатуру в синий цвет акцента после каждой смены профиля.

- Пока запущен G HUB — клавиатуру не трогать (только заряд). Без G HUB — подсветка, G-клавиши, макросы.
- Профили M1–M3 во встроенной памяти клавиатуры (HID++ `0x8100`; сначала проверить, есть ли у G915/G913).
  Режим «управляет программа» — только для живых эффектов; при выходе — всегда возврат в обычный.
- Весь обмен HID++ — один поток-владелец и очередь; программный id запроса по кругу 1–15; каждая запись
  с проверкой ответа и повтором; модель «желаемого состояния» и сверка после пробуждения/переподключения
  (0x41, 0x1D4B, ввод после простоя, нажатие M); нажатия M объединяются; журнал всех событий.
- Простые G-клавиши — в памяти клавиатуры; сложные макросы — PulseBar в отдельном потоке.
- Приглушение при простое остаётся; возврат яркости с проверкой и повтором.
- Полная замена G HUB — после недели без сбоев.
- Разбор сбоев 1.1.0 (подсветка слетает, M1 то возвращает, то нет, клавиатура гаснет) — в HISTORY.md за 30.10.2026.

## 2.3 — модуль Logitech заново (согласован 31.10.2026, два раунда вопросов; бета 2.3.0-beta.1 — 31.10.2026)

Режим работы:
- Пока PulseBar запущен, клавиатура всегда в режиме PulseBar (HID++ `0x8100` режим 2, «программный» как в G HUB):
  подсветка, M1–M3, MR и G1–G5 — у PulseBar. Переключения «память / PulseBar» на ходу нет.
- PulseBar закрыт, упал, ПК выключается → клавиатура в своей памяти (режим 1), на профиле с тем же номером.
- G HUB запущен → PulseBar отпускает клавиатуру (только заряд); закрылся → забирает обратно (как в 2.2).

Профили — ровно три (M1–M3). В каждом:
- подсветка клавиш и логотипа: эффект из списка прошивки (`0x8071`: статичный, дыхание, цикл, волна — что сообщит
  клавиатура) или режим «по клавишам» — базовый цвет и свои цвета отдельных клавиш (`0x8081`), статично;
  с 2.3.0-beta.4 анимации при запущенном PulseBar рисует сам PulseBar (G915 в режиме PulseBar эффекты не показывает);
- яркость; G1–G5 и MR (шестая назначаемая клавиша): сочетание, медиа, текст, запуск, макрос;
- список программ для автопереключения.

Автопереключение: программа в фокусе → её профиль; ушла из фокуса → профиль, выбранный вручную последним; нажатие M
при открытой программе действует, пока не сменится активная программа.

Приглушение: N минут без ввода на ПК → X%; экран выключен / ПК заблокирован / сон → подсветка гаснет; любое
нажатие — сразу обратно; заряд G915 ниже 15 % → яркость не выше 30 %.

Память клавиатуры (для работы без PulseBar):
- пишется сама после сохранения профилей, только если изменились цвета зон, G-клавиши или приглушение; перед первой
  записью — полная копия, после записи — проверка обратным чтением;
- профиль «по клавишам» → в память его базовый цвет; G-клавиши с текстом, программой, макросом без PulseBar молчат;
- кнопки «Вернуть заводские» и «Копия» остаются.

Интерфейс: всё во вкладке Logitech окна настроек, включая редактор цветов клавиш — картинка по раскладке, которую
сообщает клавиатура (`0x4540`), кисть с протяжкой, быстрые группы (все, WASD, стрелки, F-ряд, цифры, NumPad, медиа),
палитра последних цветов, копирование цветов из другого профиля, изменения сразу видны на клавиатуре. Старое окно
Logitech (WinForms) удаляется. Активный профиль — только лампочки M на клавиатуре.

Заряд: на строке клавиатура и мышь, которой пользовались последней; в подсказке — все устройства (мыши Logitech,
Razer Naga V3 Pro).

Устройства: G915 (ноутбук), G913 (ELLE, проверка позже), мыши Logitech, Razer Naga V3 Pro.

Код — с нуля, по слоям, старый код модуля удаляется:
1. транспорт HID++ — один поток-владелец, очередь запросов, программный id 2–15 по кругу, повторы при «занято»;
2. устройство — карта функций, состояние (нет связи / спит / готово), имя, заряд;
3. «желаемое состояние» (профиль, кадр подсветки, яркость, лампочки M) и сверка после каждого события
   (подключение, пробуждение, ввод после простоя, смена профиля);
4. клавиши G/M/MR — только фронт нажатия, без двойных срабатываний;
5. запись памяти клавиатуры.
Каждый слой проверяется на записанных данных клавиатуры. `logitech.json` переносится автоматически, старый файл —
копией.

Порядок: (1) диагностика `--logi-diag` — пользователь при закрытом G HUB нажимает M1–M3, MR, G1–G5, журнал сырых
событий становится тестовыми данными; (2) слои модуля с тестами; (3) вкладка и редактор; (4) бета 2.3.0-beta.1,
проверка пользователем по списку.

Статус 01.11.2026: бета 2.3.0-beta.4. В режиме PulseBar G915 эффекты прошивки не рисует — подсветка цветами по
клавишам; дыхание, цикл и волну PulseBar рисует сам, 10 кадров в секунду (решение пользователя, отменяет «без
программных анимаций»); в памяти клавиатуры они остаются эффектами прошивки. Служба Logitech LampArray мешает — у
пользователя отключена.

Статус 31.10.2026: шаги 1–4 сделаны (журнал, 30 тестов, вкладка, бета). Форматы сверены с журналом G915, кадр
подсветки и запись памяти проверены на клавиатуре по журналу пакетов. Ждёт проверки пользователем по списку;
G913 на ELLE — позже.
