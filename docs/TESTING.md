# PulseBar: чек-лист для тестировщика

Для своих ПК в домашней сети. Что-то не так — опишите и отправьте отчёт (раздел «Как сообщить» внизу).

## Перед началом

- [ ] ПК видит общую папку NAS Leo (`\\192.168.1.61\Leo`, обычно диск N:). Если нет — подключите её
      (`N:\AI\Tools\ELLE-setup\1-map-nas-drive.cmd`, пользователь NAS Papa), иначе отчёты будут ждать в очереди.
- [ ] Установлена последняя бета: **О программе → Получать бета-версии → Проверить обновления**.
- [ ] **О программе → Собирать данные для отладки** включено. Там же виден ID этого ПК (`pc-…`) — по нему отчёты
      лежат на NAS в `N:\AI\Tools\PulseBar\reports\<ID>\`.

## Установка

- [ ] Установщик прошёл без ошибок; у PulseBar в «Пуске» есть значок (зелёный пульс).
- [ ] Строка запускается с Windows (если при установке отмечен автозапуск).
- [ ] Температура процессора видна (служба PulseBarSensor и драйвер PawnIO). Если вместо неё «—» — отправьте отчёт.

## Строка на панели задач

- [ ] Строка встала в панель задач и не перекрывает значки трея.
- [ ] После смены масштаба экрана, переключения тёмной и светлой темы, перезапуска Проводника строка на месте.
- [ ] Панель с автоскрытием, вторым монитором, сверху экрана — строка ведёт себя разумно (или опишите, как).
- [ ] В полноэкранной игре строка не мешает.

## Показатели

- [ ] Загрузка CPU и GPU примерно как в Диспетчере задач; температура CPU правдоподобна.
- [ ] Ноутбук с двумя видеокартами: показана нужная, спящая дискретная видеокарта не просыпается.
- [ ] VRAM и RAM похожи на Диспетчер задач.

## Вид

- [ ] «Одна строка» и «Две строки» переключаются; режим правки двигает элементы; разделители добавляются.
- [ ] **Свой вид**: сохранить, переключиться на другой готовый вид, загрузить свой — всё вернулось, включая
      расположение и разделители.
- [ ] **Расположение на панели задач → Значки заряда**: порядок меняется, пары в «Двух строках» правильные.

## Клавиатура, мышь, наушники

- [ ] Вкладки называются по моделям; **Определить** находит устройства; список совпадает с подключёнными.
- [ ] Заряд на панели совпадает с тем, что показывает сама клавиатура, мышь или Windows (наушники — **Bluetooth и
      устройства**).
- [ ] Клавиатура Logitech G: подсветка по профилю, M1–M3, G-клавиши, кнопка яркости, после сна зажигается любой
      клавишей. Другие модели Logitech — нажмите **Сохранить отчёт об устройствах** и отправьте отчёт.
- [ ] Выключенный переключатель («Клавиатуры в PulseBar» и т. п.) убирает устройство с панели.

## ИИ (если есть подписки)

- [ ] Claude: проценты и время сброса совпадают с claude.ai.
- [ ] ChatGPT (Codex), Grok, DeepSeek — если вы в них вошли.

## Как сообщить

1. **О программе → Что случилось?** — опишите: что делали, что ожидали, что увидели.
2. Нажмите **Отправить**. В отчёт попадут журналы, сведения о системе, настройки без ключей и снимок панели задач;
   имя ПК, пользователя, почта и адреса устройств заменяются. **Показать** — посмотреть, что именно ушло.
3. Падения и ошибки отправляются сами, плюс раз в сутки короткий отчёт — делать ничего не нужно.
