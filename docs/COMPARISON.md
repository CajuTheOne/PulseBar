# PulseBar и Claude Code Usage Monitor: как встроиться в панель задач

Разбор от 20.10.2026. Повод: виджет Claude Code Usage Monitor на панели задач не моргает и имеет свою иконку в трее.

## Что это за программа

| | |
|---|---|
| Название | Claude Code Usage Monitor, Code Zeno Pty Ltd, версия 2.19.4 |
| Установка | winget, `%LOCALAPPDATA%\Microsoft\WinGet\Packages\CodeZeno.ClaudeCodeUsageMonitor_Microsoft.Winget.Source_8wekyb3d8bbwe\claude-code-usage-monitor.exe` |
| Язык | Rust (в исполняемом файле строки `rustc`, `winit`), один файл 7,6 МБ |
| Права | обычные (без администратора) |

Исходники не смотрелись. Выводы сделаны по окнам процесса (перечисление `EnumWindows`/`EnumChildWindows`)
и по именам функций Windows API внутри исполняемого файла.

## Как он устроен

### Виджет на панели задач — дочернее окно самой панели

- Окно класса `ClaudeCodeUsageMonitor` с родителем `Shell_TrayWnd`, т.е. вставлено **внутрь** панели задач через `SetParent`.
- Стили: `WS_CHILD | WS_VISIBLE | WS_CLIPSIBLINGS` (`0x54000000`) и
  `WS_EX_NOACTIVATE | WS_EX_LAYERED | WS_EX_TOOLWINDOW` (`0x08080080`).
- Рисуется через `UpdateLayeredWindow` (попиксельная прозрачность), как PulseBar.
- `SetWinEventHook` — по всей видимости, следит за перемещением/изменением панели.
- Несколько скрытых окон `CCUMThemeMirror` («Usage theme mirror») — судя по названию, отслеживают тему Windows.

Почему не моргает: окно — часть панели. Когда Проводник поднимает панель наверх или перерисовывает её, дочернее
окно поднимается вместе с ней; бороться за z-порядок не нужно. Скрытие панели в полноэкранном режиме и автоскрытие
работают сами собой.

### Иконка в трее

- `Shell_NotifyIconW` — обычная иконка области уведомлений; картинка (число, например «19») рисуется программой и
  превращается в иконку через `CreateIconIndirect`, обновляется `NIM_MODIFY` вместе с подсказкой
  («Claude Code (Default) 5h: 0% | 7d: 21%»).
- Рисует и показывает иконку сам Проводник — моргать нечему.

## Сравнение с PulseBar

| | PulseBar (сейчас) | Claude Code Usage Monitor |
|---|---|---|
| Окно на панели | отдельное окно верхнего уровня «поверх всех» над панелью | дочернее окно `Shell_TrayWnd` |
| Z-порядок | держится программно: проверка каждую секунду, при смене активного окна и через 120 мс после событий | не нужен — окно часть панели |
| Полноэкранный режим, автоскрытие | своя логика | работают сами |
| Перезапуск Проводника | окно продолжает жить, панель ищется заново | дочернее окно уничтожается вместе с панелью — нужно пересоздавать по `TaskbarCreated` |
| Связь с Проводником | нет: зависание PulseBar не влияет на панель | окна разных процессов в отношении родитель–потомок: Windows связывает их очереди ввода; зависание программы может подвесить ввод панели |
| Права | администратор (температура CPU через PawnIO) | обычные |
| Иконка в трее | нет | есть, с числом и подсказкой |

## Что это значит для PulseBar

### Вариант 1. Встроить строку в панель задач (как у монитора)

- Плюсы: никакого моргания и пропадания по определению; меньше кода про z-порядок и полноэкранный режим.
- Риски и работа:
  - Вся работа потока окна должна быть быстрой — сейчас опрос датчиков ~2 мс, допустимо; но любое зависание
    отразится на панели задач. Опрос датчиков лучше вынести в отдельный поток.
  - Пересоздание окна после перезапуска Проводника.
  - **PulseBar работает с правами администратора, Проводник — без.** `SetParent` окна процесса с высоким уровнем
    целостности в окно процесса с обычным нужно проверить: UIPI может блокировать часть сообщений между ними.
    Если не заработает — разделить программу на две части: обычное окно (без прав) и маленький помощник с правами
    только для чтения температуры через PawnIO.
  - Нынешний способ (окно поверх панели) оставить запасным, если встроиться не удалось.

### Вариант 2. Иконки в трее

- `Shell_NotifyIconW` + картинка, нарисованная программой: например, иконка с загрузкой CPU в процентах или
  температурой, цвет по порогу; подсказка со всеми значениями; меню по правому клику на иконке.
- Ограничение: иконка 16×16 при 100 % (24×24 при 150 %) — помещаются 2–3 цифры, поэтому это дополнение к строке,
  а не замена.
- Иконку видно даже когда строку закрыли приложения на панели задач; Windows 11 может прятать её в меню скрытых
  значков, пока пользователь не закрепит.
